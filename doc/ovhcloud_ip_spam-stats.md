## ovhcloud ip spam-stats

Show what an address sent while the anti-spam system held it

```
ovhcloud ip spam-stats <ip_block> <ip> [flags]
```

### Options

```
      --filter stringArray   Filter results by any property using https://github.com/PaesslerAG/gval syntax
                             Examples:
                               --filter 'state=="running"'
                               --filter 'name=~"^my.*"'
                               --filter 'nested.property.subproperty>10'
                               --filter 'startDate>="2023-12-01"'
                               --filter 'name=~"something" && nbField>10'
      --from string          Start of the window, RFC3339 (defaults to the date the address was blocked)
  -h, --help                 help for spam-stats
      --to string            End of the window, RFC3339 (defaults to now)
```
